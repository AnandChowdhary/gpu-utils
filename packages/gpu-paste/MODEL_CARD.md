# Model card: gpu-paste

## Task
Understand pasted text: detect what it is and extract structured fields, on-device.
Input: arbitrary clipboard text. Output: a `kind` (22 values), a confidence, entity
`spans`, a `parsed` payload and diagnostics. See README.md for the exact layering: 15 kinds
and 10 span kinds are decided by validated rules; the model decides 6 kinds and 6 span kinds.

## Architecture
- Tokenizer: character-class runs (`@gpu-utils/runtime` `tokenize()`); 10 hashed feature ids
  per token (word 1024, consonant skeleton 256, shape 8, 2-char prefix 128, 2-char suffix
  128, UTF-16 length 16, column-in-line 6, line-from-start 5, line-from-end 3, bias 1),
  no learned vocabulary
- Family: `ScanTagger(feature_rows=1575, hidden=32, tags=13, pooled_out=6, scan_layers=1)`
  from `gpu_utils_training.models`, unmodified. The CPU forward pass is the runtime's
  `scanTaggerForward` and the WebGPU path is `runScanTagger` on the canonical
  `scan_tagger.wgsl` (both parity-tested against the Python reference on every CI run).
- Embedding: one 1,575 × 32 table, summed per token
- Sequence mixing: one bidirectional gated affine scan (`h = a·h₋₁ + (1−a)·tanh(u)`,
  `a = σ(x Wa + ba)`, 32 channels per direction) → residual 5-tap depthwise conv over the
  64 concatenated channels → mean-pooled context (64)
- Heads: the family's per-token head `relu([x_t ‖ ctx] W + b)` 128 → 64 → 13 BIO labels
  (O + B/I × person, company, address, date, money, phone), decoded with the runtime's
  constrained Viterbi (`bioTransitions` + `bioStartMask`, no learned CRF); the family's
  pooled head `relu(ctx W₁ + b₁) W₂ + b₂` 64 → 64 → 6 kinds (address, contact, prose,
  list, code, markdown). `src/index.ts` splits the two outputs; nothing model-specific
  lives in the package.
- Parameters: 68,659 (50,400 embedding + 18,259 scan/conv/heads); v2 custom model: 66,339
- Quantization: int6 symmetric per-tensor, quantization-aware training (STE) from epoch 1
  through `gpu_utils_training.loop.train` (AdamW, warm-up + cosine, best checkpoint)
- Inference windows: 512 tokens; kind logits are averaged over windows (on WebGPU all
  windows of one paste run as a single batched dispatch)

## Training data
Synthetic-first, 160,000 training examples + 8,000 held-out (different seed), generated by
`training/gpu_paste/data.py`:
- **address** (15 %): Faker street/city/postcode pieces laid out in 15+ national formats
  (US, UK, CA, AU, NZ, IN, IE, DE, AT, CH, FR, ES, MX, IT, NL, BR, PT, SE, PL, TR, CZ, DK,
  NO, FI, HU, RO, RU, ID, JP, KR, CN), one-line and multi-line, PO boxes, country lines
- **contact** (18 %): signatures, labelled cards, one-liners, business cards, bare names,
  company + address blocks, header lines ("Kontakt", "Guest:") in EN/DE/FR/ES
- **prose** (22 %): 130+ filler sentences (incl. capitalised non-entities: products,
  places, codes, units) and 70+ slot templates with person / company / address / date /
  money / phone / email / url / code slots, 1–5 sentences, EN/DE/FR/ES/PT
- **list** (12 %): 20 bullet styles, comma lists, agendas with times, quantities, reference
  codes, people-with-status, header lines
- **code** (12 %): templated snippets in 16 languages (JS, TS, Python, Go, Rust, Java, C/C++,
  Ruby, Shell, SQL, CSS, PHP, Swift, Kotlin, C#, YAML/TOML/env)
- **markdown** (10 %): headings, paragraphs, bullets, links, fences, quotes, tables, task
  lists, emphasis
- **structured, kind masked** (7 %): JSON, CSV/TSV, HTML, logs, key=value, e-mail headers
  with entities inside (trains the span head only)
- **single entity** (4 %): a bare person/company/address/date/money/phone
- Money in 20+ locales (~100 surface forms), dates in ~110 forms (ISO, numeric, month
  names in EN/FR/DE/ES, relative phrases, times), phones in ~55 national formats
- Noise: case flips, leading/trailing whitespace, typo-free (see limitations)

Sources and licences (nothing below ships in the package; see THIRD_PARTY_NOTICES.md):
- Faker (MIT) for names, addresses, companies in 30+ locales
- US Census Bureau 1990 name files (public domain), downloaded at training time
- SEC EDGAR `company_tickers.json` (public domain), downloaded at training time
- Not used: OpenAddresses (per-source, share-alike sources), libpostal/gpu-postal corpora
  (ODbL), CoNLL-style NER (research licences)

The generator was revised once after inspecting failure *categories* on the unfamiliar set
(missing: first-name-only people, venue-style companies, units/quantities, reference codes,
agenda times, capitalised non-entities, header lines). Both the pre-revision (v1) and
post-revision (v2, shipped) numbers are reported below; the v2 unfamiliar numbers are
therefore not a clean estimate of generalisation. The set itself was never edited after
being written.

## Limitations and intended use
- Probabilistic for the six learned kinds and six learned span kinds; deterministic
  elsewhere. Not a validator: `email`/`url`/`phone` mean "looks like", not "valid".
- Trained only on synthetic text; no typos, OCR noise or non-Latin word boundaries in
  training. CJK text is one letter-run per line for the tokenizer.
- Over-tags entities in real prose (see unfamiliar precision); use span `confidence`
  (mean token probability) and `diagnostics.kindProbabilities` to gate UI actions.
- Single-label kind; long mixed pastes are classified by the average over 512-token windows.
- Day/month order in `03/04/2024` is guessed and flagged in `diagnostics.notes`.
- English-centric relative dates ("next Tuesday") in rules; other languages only via the
  model's span head.
